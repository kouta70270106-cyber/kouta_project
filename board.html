    REPORT
    冒 険 を 報 告 す る
    • 1.
      Claude Code を開く ターミナルまたは IDE から Claude Code を起動する。
    • 2.
      Google Drive MCP を認証する 未認証の場合は /mcp と入力し「Google Drive」を選んで OAuth 認証を完了させよ。
    • 3.
      冒険記録を書き出すよう命じる 以下のようにClaudeに依頼する：
      Google Drive に「冒険報告書」というドキュメントを作成し、
      私の現在の冒険記録（Lv・討伐数・クエスト状況）を書き出してください。
    • 4.
      ドキュメントを確認・共有する 作成されたドキュメントの URL を受け取り、仲間と共有せよ。冒険の証が外界に刻まれる。
