# ボス画像 生成指示書

## 作業手順

1. 下のプロンプトを **1つずつ** Gemini に貼り付けて画像を生成
2. 生成した画像を以下のフォルダに保存：
   `C:\Users\kouta\work\kouta_project\public\images\characters\`
3. ファイル名を **左の名前（例：boss_inferno.png）** に変更して保存
4. 全部揃ったら Claude に「ボス画像揃いました」と伝える → 自動でリネーム＆実装してもらう
