# ゲームメカニクス仕様書 — 永遠の旅人

## ダメージ計算式

### 物理攻撃
```
ダメージ = max(1, 攻撃側ATK - 防御側DEF / 2)
防御時 (ガード): ダメージ × 0.5
```

### 魔法攻撃
```
魔法ダメージ = max(1, 呪文power + floor(使用者ATK × 0.3) - floor(敵DEF × 0.3))
```

### 回復魔法
```
回復量 = floor(呪文power × (1 + プレイヤーLv × 0.05))
```

---

## レベルスケーリング式（GameState.scaleMonster）

```js
scale = 1 + (playerLevel - 1) × 0.12
scaledHP  = floor(baseHP  × scale)
scaledATK = floor(baseATK × scale)
scaledDEF = floor(baseDEF × scale)
```

`noScale: true` のモンスター（レアスライム等）はスケーリングなし。

## 新モンスター追加時の基準

| レアリティ | baseHP | baseATK | baseDEF | EXP目安 | Gold目安 |
|---|---|---|---|---|---|
| common | 15〜80 | 3〜12 | 1〜8 | 10〜45 | 1〜20 |
| uncommon | 50〜160 | 13〜28 | 3〜20 | 60〜100 | 12〜50 |
| rare | 200〜500 | 25〜50 | 15〜40 | 200〜400 | 50〜200 |
| legendary | 50〜900 | 3〜100 | 30〜50 | 50〜1200 | 5〜600 |

**バランス原則:**
- ATKとDEFはトレードオフを意識する（高ATKなら低DEF、高DEFなら低ATK）
- EXPはbaseHPとbaseATKの合計 ÷ 2 を目安にする
- レアリティが上がるほど特殊な役割（超高守備・超高火力など）を持たせる
